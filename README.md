# そらいろ寄せ書き（私的利用向けプロトタイプ）

青空・飛行機をテーマにした寄せ書きWebアプリです。タイトル別に色紙を3つ作り、専用URLを共有してメッセージを集め、ブラウザの印刷機能からPDF保存できます。花柄・シンプルのデザインもあります。

## まず試す（ローカルデモ）

1. `index.html` をブラウザで開きます。
2. 「新しい寄せ書きを作成」から3人分をそれぞれ作ります。
3. 各色紙の「参加URLをコピー」を押して、参加用URLを確認します。
4. 「参加画面を開く」で自分で投稿テストできます。
5. 管理画面の「PDF保存・印刷」を押し、印刷先で「PDFに保存」を選びます。

**重要：このままのデモでは、データは開いたブラウザの localStorage に保存されます。別のスマホから投稿しても管理者の画面には反映されません。** URLは同じブラウザで試すためのものです。実際にLINE等で配布するには、下記のオンライン化が必要です。

## オンライン版にするには

このプロトタイプを本当に複数端末で共有するには、静的ホスティング（例：Netlify / Vercel）と共有データベース（例：Supabase）が必要です。Supabaseプロジェクトの作成、テーブル設定、公開URLの設定を行ってから、フロントエンドをSupabaseに接続してください。公開用キーだけをフロントエンドに置き、秘密の `service_role` キーは絶対にブラウザへ入れないでください。

現時点のファイルは、すぐ試せるUIプロトタイプです。オンライン共有・管理者認証はまだ実装されていません。第三者にURLを配る前に、投稿制限、スパム対策、管理者認証、データ削除を実装・検証してください。

## 推奨するオンライン版のデータ設計

- `boards`: `id`（ランダムUUID）, `title`, `recipient`, `theme`, `created_at`, `owner_id`
- `messages`: `id`, `board_id`, `name`, `body`, `created_at`
- 投稿URLは予測されにくいランダムなIDを使用
- 管理画面は認証必須にし、所有者だけが編集・削除できるRLSポリシーを設定
- ゲストは該当色紙への投稿だけ許可。全色紙・全投稿の一覧取得を許可しない
- 文字数制限、連投制限、投稿の非表示/削除、締切設定を追加

## PDFについて

「PDF保存・印刷」はブラウザの印刷ダイアログを使います。印刷画面で「PDFに保存」を選択してください。現状のデザインはプレビュー用で、20人のメッセージはブラウザ幅や文字数によって見え方が変わる場合があります。配布前に実際の印刷サイズで確認してください。
